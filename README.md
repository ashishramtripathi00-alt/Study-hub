# Study Hub - Free Physics Wallah Learning App

A comprehensive mobile application that provides free access to all Physics Wallah batches, lectures, and educational content. Study Hub brings high-quality physics education to everyone, completely free of cost.

## 🎯 Features

### Core Features
- ✅ **Free Access**: All paid batches and lectures are completely free
- ✅ **Video Lectures**: Stream high-quality video lectures with adaptive quality
- ✅ **Offline Download**: Download lectures to watch offline
- ✅ **Progress Tracking**: Track your learning progress and course completion
- ✅ **User Authentication**: Secure sign-up and login
- ✅ **Course Curriculum**: Complete course structure with chapters and topics
- ✅ **Assignments & Practice**: Solve assignments and practice problems
- ✅ **Doubt Resolution**: Post and resolve doubts
- ✅ **Push Notifications**: Get notified about new lectures and updates
- ✅ **Watchlist**: Save lectures to your watchlist
- ✅ **Search & Filter**: Search and filter courses by difficulty and topics
- ✅ **Dark Mode**: Eye-friendly dark mode support
- ✅ **Multi-language Support**: Support for multiple languages

## 🛠️ Tech Stack

### Frontend
- **React Native** with **Expo** for cross-platform mobile development (iOS & Android)
- **Redux Toolkit** for state management
- **React Navigation** for app navigation
- **Native Base** for UI components

### Backend
- **Node.js** with **Express.js** for REST API
- **JWT** for authentication
- **MongoDB** for database

### Database
- **MongoDB** for data storage
- **Firebase Storage** for media hosting and streaming

### Video Streaming
- **HLS (HTTP Live Streaming)** for adaptive bitrate streaming
- **react-native-video** for video playback

### Additional Services
- **Firebase Authentication** for user management
- **Firebase Cloud Messaging** for push notifications

## 🚀 Quick Start

### Backend Setup
```bash
cd backend
npm install
cp .env.example .env
npm run dev
```

### Mobile App Setup
```bash
cd mobile
npm install
expo start
```
